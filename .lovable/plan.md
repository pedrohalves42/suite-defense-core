
1. **Definição de Persona Técnica**: Atribuição do papel de Engenheiro de Software Sênior e Auditor de Segurança para elevar o nível técnico da análise.
2. **Estruturação de Resposta (Output Schema)**: Implementação de um formato fixo (Diagnóstico, Causa Raiz, Código Corrigido, Justificativa) para garantir que nenhuma informação crítica seja omitida.
3. **Refinamento de Critérios de Qualidade**: Adição de requisitos específicos de Clean Code, performance e segurança cibernética.
4. **Prompt Reescrito**: 
   "Aja como um Engenheiro de Software Sênior e Especialista em Auditoria de Código. Realize uma análise técnica profunda do código fornecido para identificar falhas lógicas, vulnerabilidades de segurança, bugs de runtime e ineficiências. Para cada problema detectado, forneça uma resposta estruturada com: 
   1) **Diagnóstico Técnico**: Descrição clara e precisa da falha.
   2) **Análise da Causa Raiz**: Explicação detalhada do motivo técnico do erro.
   3) **Correção Exata**: Código revisado, otimizado e pronto para implementação imediata.
   4) **Justificativa e Validação**: Explicação de como a correção resolve o problema e melhora a estabilidade/performance do sistema.
   O objetivo final é garantir um código semanticamente correto, seguro e de alta performance."
